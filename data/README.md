# Data layout

## Kaggle competition files (optional)

Download from the [Home Credit Default Risk](https://www.kaggle.com/c/home-credit-default-risk) competition and place under `data/raw/`:

- `application_train.csv`
- `application_test.csv`
- `bureau.csv`
- `bureau_balance.csv`
- `previous_application.csv`
- `installments_payments.csv`
- `POS_CASH_balance.csv`
- `credit_card_balance.csv`

## No raw data? Use synthetic demo mode

If the CSVs above are **not** present, the project still works:

1. `make preprocess` — builds `data/processed/merged_{train,test}.pkl` from synthetic sample tables
2. `make train` — trains a compact demo ensemble (3-fold CV, SHAP off) on that processed data
3. `make smoke` — auto-trains the demo model if `artifacts/models/ensemble_model.pkl` is missing

Synthetic data is intended for CI, local smoke tests, and reviewer walkthroughs without downloading ~2.5 GB of Kaggle files. Metrics will **not** match competition-grade results.
